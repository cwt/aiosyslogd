# aiosyslogd v1.5.0: Pluggable Activity Reporting Engine, CLI, and Web UI

We are excited to release aiosyslogd v1.5.0, introducing a pluggable activity reporting architecture, a standalone command-line analysis tool, and interactive web dashboard integration.

Key Highlights:

* **Pluggable Activity Reporting Engine (`aiosyslogd.activity`):**
    * **Asynchronous Chunked Aggregation:** Processes syslog records from SQLite in efficient asynchronous chunks with SQLite FTS5 full-text indexing.
    * **Time Bucketing:** Groups user sessions and calculates active usage minutes bucketed across users, application categories, and individual applications.
    * **Extensible Parser Architecture:** Introduced `BaseActivityParser` interface, allowing developers to create custom syslog parsing modules for different device types and vendors.
    * **FortiOS Parser:** Built-in `FortiOSParser` extracting application names, usernames, and categories from FortiOS traffic and security log events.

* **Dedicated Activity CLI (`aiosyslogd-activity`):**
    * **Standalone Terminal Utility:** Registered console script for on-demand user activity analysis directly from the terminal.
    * **Responsive Output:** Features terminal-width detection with single-column and dual-column table rendering powered by `prettytable`.
    * **Flexible Filtering:** Supports custom SQLite database paths, FTS5 queries, custom time windows, and user filtering.

* **Web UI & REST API Dashboard:**
    * **Interactive Activity View:** New `/activity` route offering an intuitive web interface to browse aggregated user sessions.
    * **JSON API Endpoint:** Added `/api/activity` endpoint for programmatic access and dynamic front-end reporting.

* **Testing & Quality Assurance:**
    * Comprehensive test suite added for the activity aggregation engine, parser implementations, and CLI commands.

This release equips administrators and analysts with powerful visibility into application and network usage directly from their syslog stream.
