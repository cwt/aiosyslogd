# aiosyslogd v1.6.0: Security Hardening, Dark Mode UI, and Web Experience Enhancements

We are excited to release aiosyslogd v1.6.0, delivering comprehensive web security hardening, full dark mode color scheme support, accessibility improvements, and key architectural modernizations.

Key Highlights:

* **Comprehensive Web Security Hardening:**
    * **Strict CSRF Enforcement:** Validated CSRF tokens across all form content encodings (including `multipart/form-data`) and state-changing REST API endpoints via `X-CSRF-Token`. Removed tokens from GET query strings to prevent token leakage.
    * **Open Redirect Protection:** Validated and sanitized the `next` target query parameter on the login endpoint against external and protocol-relative redirect attacks.
    * **Path Traversal Protection:** Added strict database file parameter validation on the `/api/activity` endpoint.
    * **Atomic Credential Persistence:** Implemented atomic file write routines and backup preservation on corrupted user databases in `AuthManager`.
    * **Admin Lockout Safeguards:** Added protections preventing administrators from accidentally demoting or locking out their own accounts.
    * **Subresource Integrity (SRI) & CSP Readiness:** Added SRI integrity hashes for external CDN assets and eliminated inline JavaScript event handlers to facilitate strict Content Security Policies.

* **Dark Mode & Modernized UI:**
    * **Dark Theme Support:** Integrated native dark mode styling utilizing Bootstrap 5.3+ color modes, accompanied by a persistent theme switcher in the top navigation bar.
    * **Log Viewer Formatting:** Applied monospace font stacks, proper whitespace wrapping, and improved visual hierarchy to syslog message tables.
    * **Form & Interaction Polish:** Upgraded boolean form controls to Bootstrap 5 switches, added password confirmation validation on account creation/updates, and optimized search filter resets to clear DOM content in-place without page reloads.

* **Accessibility & Usability (A11y):**
    * **Accessible Navigation:** Added a "Skip to main content" link and active route highlighting with `aria-current="page"` across all navigation links.
    * **Data Table Semantics:** Enhanced table header scope attributes for screen readers.
    * **Favicon:** Added a modern SVG favicon to all web templates.

* **Framework & Backend Modernization:**
    * **Quart 0.22+ Compatibility:** Upgraded web framework dependency bounds and refactored logging to utilize Loguru directly without mutating Quart's internal logger.
    * **FTS5 Operational Error Handling:** Gracefully caught and formatted SQLite full-text search operational syntax errors.
    * **Template Architecture:** Added `extra_css` and `extra_js` Jinja2 blocks to `base.html` for clean layout inheritance.
    * **Optimized Docker Builds:** Enhanced multi-stage Docker build layers and refreshed bundled web UI assets.

This release represents a significant step forward in security, accessibility, and user experience across the entire aiosyslogd web management interface.
