# aiosyslogd v1.4.0: Modernized Gemini API & Library Updates

We are excited to release aiosyslogd v1.4.0, featuring a streamlined integration with Google's modern Generative AI SDK, updated Gemini model preferences, and updated core dependencies.

Key Highlights:

* **Modernized Google Gen AI Integration:**
    * **Exclusive `google-genai` Support:** Completely migrated to Google's official `google-genai` SDK for natural language to FTS5 query conversion.
    * **Removed Deprecated Fallback:** Dropped legacy fallback code for the deprecated `google-generativeai` package, simplifying the codebase and dependency tree.
    * **Updated Model Preference Hierarchy:** Updated the default AI model selection order to leverage `gemma-4-26b-a4b-it`, `gemini-pro-latest`, and `gemini-flash-latest`.

* **Documentation & Privacy Updates:**
    * **Updated README:** Clarified integration requirements for the `gemini` optional dependency group (`poetry install -E gemini`).
    * **Refined Privacy Notice:** Clarified how API keys and generated search queries interact with the Gemini API.

* **Dependency Updates:**
    * Updated core and development dependencies including `cryptography`, `requests`, `aiohttp`, `black`, and `pyjwt` to incorporate the latest stability and security patches.

This release modernizes the AI query translation subsystem while ensuring optimal performance and compatibility with Google's latest Gemini models.
