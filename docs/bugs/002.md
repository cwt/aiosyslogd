# Open Redirect Vulnerability on Login Endpoint

## Bug Summary
The `/login` route reads the `next` query parameter from the request URL and immediately passes it to Quart's `redirect()` function upon successful authentication without any validation.

## Severity & Impact
- **Severity**: High (Security Vulnerability)
- **Impact**: Attackers can construct phishing campaigns pointing victims to a legitimate `aiosyslogd` instance with a malicious `next` parameter (e.g. `http://aiosyslogd.corp.local/login?next=https://attacker-login.com`). After entering their valid credentials, the victim is redirected to the attacker's domain, enabling credential harvesting or malware delivery.

## Affected Components
- File: [web.py](../../aiosyslogd/web.py#L188-L189)
- Function: `login()`

```python
if auth_manager.check_password(username, password):
    session["username"] = username
    next_page = request.args.get("next")
    return redirect(next_page or url_for("index"))
```

## Root Cause Analysis
`next_page` is used without checking if it contains an absolute URL, protocol-relative URL (`//evil.com`), or external hostname. 

## Steps to Reproduce
1. Open the URL `http://localhost:5141/login?next=https://example.com` in a browser.
2. Sign in with valid user credentials.
3. Observe that after successful authentication, the browser is navigated to `https://example.com` rather than a page within the application.

## Proposed Remediation
Validate that `next_page` is a safe relative path before redirecting:

```python
from urllib.parse import urlparse

def is_safe_url(target: str | None) -> bool:
    if not target:
        return False
    ref_url = urlparse(request.host_url)
    test_url = urlparse(target)
    # Target must not specify an external scheme or netloc, or must match host
    return (not test_url.scheme and not test_url.netloc and target.startswith("/") and not target.startswith("//"))

# In login():
next_page = request.args.get("next")
if next_page and is_safe_url(next_page):
    return redirect(next_page)
return redirect(url_for("index"))
```
