# Consolidate API Fetch Helper and CSRF Token Handling

## Overview
Fetch calls across `index.html` and `profile.html` repeatedly extract `<meta name="csrf-token">`, construct request headers, parse JSON payloads, and format catch errors independently.

## Motivation & Impact
- **DRY Code**: Eliminates boilerplate across all frontend fetch requests.
- **Reliable CSRF Protection**: Centralizes token extraction from `<meta name="csrf-token">`.
- **Consistent Error Handling**: Ensures all API error responses are formatted uniformly.

## Proposed Implementation
Define `window.apiFetch` in a shared script or `base.html`:

```javascript
async function apiFetch(url, options = {}) {
    const metaToken = document.querySelector('meta[name="csrf-token"]');
    const csrfToken = metaToken ? metaToken.getAttribute('content') : '';
    
    const headers = {
        'Content-Type': 'application/json',
        'X-CSRF-Token': csrfToken,
        ...(options.headers || {})
    };

    const response = await fetch(url, { ...options, headers });
    const data = await response.json().catch(() => ({}));

    if (!response.ok) {
        throw new Error(data.error || `HTTP ${response.status}: ${response.statusText}`);
    }
    return data;
}
```
