# Optimize Dynamic Highlighter In-Place Reset without Page Reload

## Overview
In `index.html`, clicking the `Remove All` highlights button invokes `resetHighlights()`:
```javascript
function resetHighlights() {
    const url = new URL(window.location.href);
    url.searchParams.delete('extract');
    window.location.href = url.toString();
}
```
This forces a full HTTP GET request and page refresh to clear client-side highlighting.

## Motivation & Impact
- **Performance**: Highlighting is an entirely client-side UI decoration. Re-executing server query logic and reloading assets introduces unnecessary latency and server load.
- **User Experience**: In-place DOM clearing is instantaneous (0ms) and preserves scroll position.

## Proposed Implementation
Update `resetHighlights()` to:
1. Clear the local `originalCasingKeys` and `keyColorMap` state.
2. Call `applyAllHighlights()` and `updateKeyListUI()`.
3. Update browser URL history without reloading:
   ```javascript
   function resetHighlights() {
       originalCasingKeys = [];
       keyColorMap = {};
       const url = new URL(window.location.href);
       url.searchParams.delete('extract');
       window.history.replaceState({}, '', url.toString());
       updateKeyListUI();
       updatePaginationLinks();
       applyAllHighlights();
   }
   ```
