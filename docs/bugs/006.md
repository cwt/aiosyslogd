# Fragile admin_required Decorator Missing User Verification

## Bug Summary
The `@admin_required` decorator accesses `session["username"]` directly and assumes that `auth_manager.get_user(session["username"])` always returns a valid, non-null `User` object.

## Severity & Impact
- **Severity**: Medium (Unhandled Exception / Fragility)
- **Impact**: If `@admin_required` is ever declared on a route without `@login_required`, or if a user's session remains active after their user record is deleted by another administrator, the request raises an uncaught `KeyError` or `AttributeError: 'NoneType' object has no attribute 'is_admin'`.

## Affected Components
- File: [web.py](../../aiosyslogd/web.py#L158-L169)
- Function: `admin_required()`

```python
def admin_required(f):
    @wraps(f)
    async def decorated_function(*args, **kwargs):
        user = auth_manager.get_user(session["username"])
        if not user.is_admin:
            await flash(
                "You do not have permission to access this page.", "error"
            )
            return redirect(url_for("index"))
        return await f(*args, **kwargs)

    return decorated_function
```

## Root Cause Analysis
1. `session["username"]` raises `KeyError` if `"username"` is not set in the session.
2. `user` can be `None` if the user was deleted, causing `not user.is_admin` to fail with `AttributeError`.

## Steps to Reproduce
1. In `web.py`, define a test route decorated solely with `@admin_required` (without `@login_required`).
2. Request the route in an unauthenticated browser session.
3. Observe the `KeyError: 'username'` 500 error.

## Proposed Remediation
Defensively check both session presence and the user object in `admin_required`:

```python
def admin_required(f):
    @wraps(f)
    async def decorated_function(*args, **kwargs):
        username = session.get("username")
        if not username:
            return redirect(url_for("login", next=request.path))
        user = auth_manager.get_user(username)
        if not user or not user.is_enabled or not user.is_admin:
            await flash(
                "You do not have permission to access this page.", "danger"
            )
            return redirect(url_for("index"))
        return await f(*args, **kwargs)

    return decorated_function
```
