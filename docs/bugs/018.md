# Add Active Route Highlighting in Top Navigation Bar

## Overview
In `base.html`, navigation links (`Home`, `Activity`, `Users`) are static. Users have no visual or screen-reader indication of which section of the application is currently active.

## Motivation & Impact
- **User Experience**: Users immediately know their current location in the application.
- **Accessibility**: Screen readers utilize `aria-current="page"` to announce the active page.

## Proposed Implementation
Bind the `active` class and `aria-current` attribute to `request.endpoint`:

```html
<li class="nav-item">
    <a class="nav-link {% if request.endpoint == 'index' %}active{% endif %}" 
       {% if request.endpoint == 'index' %}aria-current="page"{% endif %} 
       href="{{ url_for('index') }}">Home</a>
</li>
<li class="nav-item">
    <a class="nav-link {% if request.endpoint == 'activity' %}active{% endif %}" 
       {% if request.endpoint == 'activity' %}aria-current="page"{% endif %} 
       href="{{ url_for('activity') }}">Activity</a>
</li>
{% if current_user.is_admin %}
<li class="nav-item">
    <a class="nav-link {% if request.endpoint in ['list_users', 'add_user', 'edit_user'] %}active{% endif %}" 
       {% if request.endpoint in ['list_users', 'add_user', 'edit_user'] %}aria-current="page"{% endif %} 
       href="{{ url_for('list_users') }}">Users</a>
</li>
{% endif %}
```
