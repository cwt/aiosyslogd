# Add Template Extension Blocks for Styles and Scripts in base.html

## Overview
Currently, `base.html` only provides `{% block title %}` and `{% block content %}`. Child templates (`index.html`, `profile.html`) dump their `<style>` blocks and `<script>` blocks inside `{% block content %}`.

## Motivation & Impact
- **DOM Placement**: Styles placed inside the `<body>` can cause flash of unstyled content (FOUC) and violate standard HTML structure recommendations.
- **Script Execution**: Scripts placed at the end of the `<body>` after libraries (e.g. `bootstrap.bundle.min.js`) ensure dependent globals are initialized before child scripts execute.

## Proposed Implementation
Update `base.html` to define explicit blocks:

```html
<head>
    ...
    <link rel="stylesheet" href="...">
    {% block extra_css %}{% endblock %}
</head>
<body>
    ...
    <main class="container">
        {% block content %}{% endblock %}
    </main>
    <script src="..."></script>
    {% block extra_js %}{% endblock %}
</body>
```
