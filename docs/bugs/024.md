# Remove Brittle Inline Hover Style Event Handlers on Action Buttons

## Overview
In `index.html`, lines 41 and 43 use inline JavaScript mouse event handlers to manipulate inline styles:
```html
<button type="button" id="gemini-btn" class="btn btn-outline-success" 
        style="color: green;" 
        onmouseover="this.style.color='white'; this.style.backgroundColor='green';" 
        onmouseout="this.style.color='green'; this.style.backgroundColor='';">✦</button>

<a href="..." class="btn btn-outline-danger" 
   style="color: red; display: flex; align-items: center; justify-content: center;" 
   onmouseover="this.style.color='white'; this.style.backgroundColor='red';" 
   onmouseout="this.style.color='red'; this.style.backgroundColor='';">↻</a>
```

## Motivation & Impact
- **Code Cleanliness**: Bootstrap classes (`btn-outline-success`, `btn-outline-danger`) already natively provide hover background and text transitions.
- **CSP Compliance**: Eliminates unnecessary inline JavaScript handlers.

## Proposed Implementation
Simplify markup to pure Bootstrap 5 utilities:

```html
{% if gemini_available %}
<button type="button" id="gemini-btn" class="btn btn-outline-success" title="Ask Gemini to create search query" aria-label="Ask Gemini">✦</button>
{% endif %}
<a href="{{ url_for('index', db_file=selected_db) }}" class="btn btn-outline-danger d-inline-flex align-items-center justify-content-center" title="Reset Search and Filters" aria-label="Reset Search and Filters">↻</a>
```
