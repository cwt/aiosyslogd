# Tailwind CSS Utility Classes Used in Bootstrap 5 Environment

## Bug Summary
`base.html` imports Bootstrap 5.3.0 from CDN. However, several templates (`index.html`, `activity.html`) use Tailwind CSS utility classes that do not exist in Bootstrap.

Examples:
- `<h1 class="text-4xl font-bold text-gray-700">`
- `<p class="text-gray-500">`
- `<form class="... rounded-lg shadow-sm ...">`
- `<h3 class="... text-gray-800">`

## Severity & Impact
- **Severity**: Low (Visual Defect)
- **Impact**: Titles, subtitles, and cards fail to adopt intended styling, rendering with browser default font sizes and square borders.

## Affected Components
- File: [index.html](../../aiosyslogd/templates/index.html#L20-L25), [index.html](../../aiosyslogd/templates/index.html#L78)
- File: [activity.html](../../aiosyslogd/templates/activity.html#L7-L11)

## Root Cause Analysis
Tailwind CSS classes (`text-4xl`, `font-bold`, `text-gray-*`, `rounded-lg`) were mixed into HTML templates without including a Tailwind stylesheet.

## Steps to Reproduce
1. Inspect the main headings on the Log Viewer or User Activity Report page using browser Developer Tools.
2. Note that classes `.text-4xl`, `.text-gray-700`, etc., match no active CSS rules.

## Proposed Remediation
Replace Tailwind classes with standard Bootstrap 5 utility classes:
- Replace `text-4xl font-bold text-gray-700` with `display-6 fw-bold text-dark` or `h1 fw-bold`
- Replace `text-gray-500` with `text-muted` or `text-secondary`
- Replace `text-gray-800` with `text-dark`
- Replace `rounded-lg` with `rounded-3`
