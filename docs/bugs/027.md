# Add Accessibility Improvements (A11y, ARIA Labels, and Table Scopes)

## Overview
Current templates lack several standard accessibility attributes:
- Missing skip-to-content link in `base.html`.
- Table header cells (`<th>`) lack `scope="col"` in `index.html`, `activity.html`, and `users.html`.
- Icon-only buttons (`✦`, `↻`) lack `aria-label` attributes.
- Modal dialogs lack `aria-labelledby` linkages.

## Motivation & Impact
- **WCAG 2.1 Compliance**: Ensures keyboard-only and screen-reader users can navigate efficiently.
- **Screen Reader Support**: Properly announces table structure and button purposes.

## Proposed Implementation
1. Add skip navigation link at the top of `base.html`:
   ```html
   <a class="visually-hidden-focusable btn btn-primary m-2" href="#main-content">Skip to main content</a>
   ```
2. Add `id="main-content"` to `<main class="container">`.
3. Add `scope="col"` to all `<th>` elements across tables.
4. Ensure all modals have `aria-labelledby="modalTitleId"`.
