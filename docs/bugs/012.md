# Unstyled Error Flash Messages (alert-error vs alert-danger)

## Bug Summary
In `base.html`, flashed messages are rendered dynamically using the flash category as part of the class name:
```html
<div class="alert alert-{{ category }} alert-dismissible fade show" role="alert">
    {{ message }}
    <button type="button" class="btn-close" data-bs-dismiss="alert" aria-label="Close"></button>
</div>
```
Throughout `web.py`, error messages are flashed with category `"error"` (e.g. `await flash("Invalid username or password.", "error")`). Because Bootstrap 5 uses `alert-danger` for error styling and has no `alert-error` class, all error messages are rendered without background colors, borders, or text styling.

## Severity & Impact
- **Severity**: Low (UI Defect)
- **Impact**: Critical error messages (authentication failures, permission denials, user validation errors) appear as plain unstyled text without red warning styling, confusing users.

## Affected Components
- File: [base.html](../../aiosyslogd/templates/base.html#L60-L68)
- File: [web.py](../../aiosyslogd/web.py#L151), [web.py](../../aiosyslogd/web.py#L164), [web.py](../../aiosyslogd/web.py#L191), [web.py](../../aiosyslogd/web.py#L334), [web.py](../../aiosyslogd/web.py#L368), [web.py](../../aiosyslogd/web.py#L375), [web.py](../../aiosyslogd/web.py#L393)

## Root Cause Analysis
Bootstrap 5 contextual alert classes are `alert-primary`, `alert-secondary`, `alert-success`, `alert-danger`, `alert-warning`, `alert-info`, `alert-light`, and `alert-dark`. `alert-error` is not recognized.

## Steps to Reproduce
1. Navigate to `http://localhost:5141/login`.
2. Enter an incorrect username or password and submit.
3. Observe the error notification: it renders as `<div class="alert alert-error ...">`, displaying unstyled text with no red background or border.

## Proposed Remediation
Map `"error"` to `"danger"` in `base.html`:

```html
{% with messages = get_flashed_messages(with_categories=true) %}
    {% if messages %}
        {% for category, message in messages %}
            {% set alert_class = 'danger' if category == 'error' else category %}
            <div class="alert alert-{{ alert_class }} alert-dismissible fade show" role="alert">
                {{ message }}
                <button type="button" class="btn-close" data-bs-dismiss="alert" aria-label="Close"></button>
            </div>
        {% endfor %}
    {% endif %}
{% endwith %}
```
