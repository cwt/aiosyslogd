# Monospace Typography and Word Breaking for Syslog Message Cells

## Overview
In `index.html`, log message cells are styled as:
```html
<td class="log-message-cell" style="word-break: break-all;">{{ log.Message }}</td>
```

## Motivation & Impact
- **Readability**: Syslog entries often contain structured key-value pairs (`key=value`), JSON blobs, IP addresses, and timestamps. Proportional fonts make column alignment and structured tokens difficult to parse visually.
- **Word Break Defect**: `word-break: break-all` splits words and dates at arbitrary character boundaries, e.g., breaking `2026-08-28` into `2026-08` and `-28`.

## Proposed Implementation
Use Bootstrap's monospace font variable with `word-break: break-word` and `overflow-wrap: anywhere`:

```css
.log-message-cell {
    font-family: var(--bs-font-monospace);
    font-size: 0.875rem;
    word-break: break-word;
    overflow-wrap: anywhere;
    white-space: pre-wrap;
}
```
