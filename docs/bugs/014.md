# Missing Margin Between Floating Form Controls on Login View

## Bug Summary
In `login.html`, the `.form-floating` wrappers for username and password inputs do not have any vertical margin classes (e.g. `mb-3` or `mb-2`).

```html
<div class="form-floating">
    <input type="text" class="form-control" id="username" name="username" placeholder="Username" required autofocus>
    <label for="username">Username</label>
</div>
<div class="form-floating">
    <input type="password" class="form-control" id="password" name="password" placeholder="Password" required>
    <label for="password">Password</label>
</div>
<button class="w-100 btn btn-lg btn-primary" type="submit">Sign in</button>
```

## Severity & Impact
- **Severity**: Low (Visual Polish)
- **Impact**: The username field, password field, and "Sign in" button vertically collide with zero pixel spacing between them, degrading login UI quality.

## Affected Components
- File: [login.html](../../aiosyslogd/templates/login.html#L11-L19)

## Root Cause Analysis
Bootstrap 5 `form-floating` elements have zero outer margin by default and require explicit margin utility classes.

## Steps to Reproduce
1. Navigate to `http://localhost:5141/login`.
2. Observe the input fields touching each other with no gap.

## Proposed Remediation
Add `mb-3` to the `.form-floating` containers and submit button:

```html
<div class="form-floating mb-3">
    <input type="text" class="form-control" id="username" name="username" placeholder="Username" required autofocus>
    <label for="username">Username</label>
</div>
<div class="form-floating mb-3">
    <input type="password" class="form-control" id="password" name="password" placeholder="Password" required>
    <label for="password">Password</label>
</div>
<button class="w-100 btn btn-lg btn-primary" type="submit">Sign in</button>
```
