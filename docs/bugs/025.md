# Upgrade User Form Checkboxes to Bootstrap 5 Switches

## Overview
In `user_form.html`, user state toggles (`Is Admin` and `Is Enabled`) use standard HTML checkboxes:
```html
<div class="mb-3 form-check">
    <input type="checkbox" class="form-check-input" id="is_admin" name="is_admin" ...>
    <label class="form-check-label" for="is_admin">Is Admin</label>
</div>
```

## Motivation & Impact
- **Modern UI**: Bootstrap 5 provides native toggle switches (`form-switch`) that provide a clearer representation of active/inactive binary states.

## Proposed Implementation
Update `user_form.html` to:
```html
<div class="form-check form-switch mb-3">
    <input type="checkbox" class="form-check-input" id="is_admin" name="is_admin" role="switch" {{ 'checked' if user and user.is_admin }}>
    <label class="form-check-label" for="is_admin">Administrator Privileges</label>
</div>
{% if user %}
<div class="form-check form-switch mb-3">
    <input type="checkbox" class="form-check-input" id="is_enabled" name="is_enabled" role="switch" {{ 'checked' if user and user.is_enabled }}>
    <label class="form-check-label" for="is_enabled">Account Enabled</label>
</div>
{% endif %}
```
