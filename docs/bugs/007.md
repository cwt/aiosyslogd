# Non-Atomic File Writes and User File Corruption in AuthManager

## Bug Summary
In `AuthManager`, the `_save_users()` method uses standard `open(self.users_file, "w")` to write user records directly to `users.json`. If the process is interrupted during write, or if multiple threads/workers perform concurrent writes, the file is left empty or partially written. On the next load, `json.load()` encounters `json.JSONDecodeError` and automatically executes `_create_default_users_file()`, permanently deleting all customized users and resetting the admin password to `"admin"`.

## Severity & Impact
- **Severity**: Medium (Data Loss & Privilege Regression)
- **Impact**: All stored user accounts, hashed passwords, and permissions can be wiped automatically, reverting the authentication system back to factory default credentials.

## Affected Components
- File: [auth.py](../../aiosyslogd/auth.py#L48-L92)
- Class: `AuthManager`
- Methods: `_load_users()`, `_save_users()`

```python
def _save_users(self):
    with open(self.users_file, "w") as f:
        json.dump(
            {
                username: user.to_dict()
                for username, user in self.users.items()
            },
            f,
            indent=4,
        )
```

## Root Cause Analysis
1. Non-atomic file truncation: `open(..., "w")` truncates the file to 0 bytes before writing JSON content.
2. In `_load_users()`, any decode error unconditionally triggers fallback recreation of default admin credentials:
   ```python
   except json.JSONDecodeError:
       logger.error(f"Error decoding JSON from {self.users_file}. Creating a new one.")
       self._create_default_users_file()
   ```

## Steps to Reproduce
1. Create multiple user accounts.
2. Simulate a partial write or truncate `users.json` to zero bytes.
3. Restart the web server.
4. Inspect `users.json`: all custom users have been replaced by the single default `admin:admin` entry.

## Proposed Remediation
1. Perform atomic file writes using a temporary file and `os.replace`:
   ```python
   import tempfile

   def _save_users(self):
       dir_name = os.path.dirname(os.path.abspath(self.users_file)) or "."
       with tempfile.NamedTemporaryFile("w", dir=dir_name, delete=False) as tf:
           temp_name = tf.name
           json.dump(
               {username: user.to_dict() for username, user in self.users.items()},
               tf,
               indent=4,
           )
       os.replace(temp_name, self.users_file)
   ```
2. In `_load_users()`, preserve corrupted files with a `.bak` extension before overwriting.
