# Unhandled OperationalError on Malformed FTS5 Query in Activity Module

## Bug Summary
The `run_activity_report` function executes SQLite FTS5 queries using `aiosqlite.connect()` and `conn.execute()` without wrapping database operations in a `try...except` block. When a user inputs an invalid FTS5 syntax (such as unbalanced quotes or invalid boolean expressions like `app:YouTube AND`), SQLite raises an `aiosqlite.OperationalError: fts5: syntax error`, resulting in an unhandled exception and an HTTP 500 response.

## Severity & Impact
- **Severity**: Medium (Application Crash / Denial of Service)
- **Impact**: Any user submitting a malformed search string triggers an unhandled 500 Internal Server Error in both the web view (`/activity`) and the API endpoint (`/api/activity`).

## Affected Components
- File: [activity/\_\_init\_\_.py](../../aiosyslogd/activity/__init__.py#L64-L204)
- File: [web.py](../../aiosyslogd/web.py#L426-L439), [web.py](../../aiosyslogd/web.py#L458-L466)
- Function: `run_activity_report()`, `activity()`, `api_activity()`

## Root Cause Analysis
The data structure `ActivityReport` defines an `error: Optional[str] = None` attribute, and the template contains `{% if report.error %}`, indicating an expectation for caught errors. However, `run_activity_report()` never catches `aiosqlite.Error` to populate `report.error`.

## Steps to Reproduce
1. Navigate to `http://localhost:5141/activity`.
2. Select an existing database.
3. In the search box, enter an invalid FTS5 query: `app:YouTube OR` or `"unterminated quote`.
4. Click **Analyze**.
5. Observe that the server raises `aiosqlite.OperationalError: fts5: syntax error` and returns an HTTP 500 error page.

## Proposed Remediation
Wrap database interactions in `run_activity_report()` with error handling:

```python
async def run_activity_report(
    db_path: str,
    search_query: str,
    filters: Dict[str, str],
    parser: Optional[BaseActivityParser] = None,
) -> ActivityReport:
    start_time = time.perf_counter()
    if parser is None:
        parser = FortiOSParser()

    try:
        db_uri = f"file:{db_path}?mode=ro"
        async with aiosqlite.connect(
            db_uri,
            uri=True,
            detect_types=sqlite3.PARSE_DECLTYPES | sqlite3.PARSE_COLNAMES,
        ) as conn:
            # ... execute queries ...
    except (aiosqlite.OperationalError, aiosqlite.DatabaseError) as e:
        return ActivityReport(
            timeframe={"from": filters.get("received_at_min", ""), "to": filters.get("received_at_max", "")},
            total_window_minutes=0,
            users=[],
            total_logs=0,
            query_time=time.perf_counter() - start_time,
            error=str(e),
        )
```
