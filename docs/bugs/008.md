# Uncaught Null Reference Crash on Profile Page when Gemini is Disabled

## Bug Summary
In `profile.html`, the Gemini configuration UI is conditionally rendered with `{% if gemini_available %}`. However, the `<script>` block at the bottom of `profile.html` executes unconditionally and directly references `document.getElementById('gemini-api-key')`, `document.getElementById('save-gemini-key')`, and `document.getElementById('clear-gemini-key')`.

When Gemini is disabled (the default when `google-genai` is not installed), these DOM queries return `null`, causing `addEventListener()` to throw an uncaught TypeError.

## Severity & Impact
- **Severity**: Medium (Client-Side Script Crash)
- **Impact**: All subsequent JavaScript execution on the profile page terminates with an uncaught exception, polluting the browser console and breaking any additional scripts loaded on the page.

## Affected Components
- File: [profile.html](../../aiosyslogd/templates/profile.html#L44-L148)
- Elements: `#save-gemini-key`, `#clear-gemini-key`, `#gemini-api-key`

```javascript
document.addEventListener('DOMContentLoaded', function() {
    // Load saved API key from localStorage if it exists
    const savedApiKey = localStorage.getItem('gemini_api_key');
    if (savedApiKey) {
        document.getElementById('gemini-api-key').placeholder = '••••••••••••••••••••';
    }
    
    // Save API key button handler
    document.getElementById('save-gemini-key').addEventListener('click', async function() {
        ...
    });
});
```

## Root Cause Analysis
The script does not guard against `null` elements when `gemini_available` evaluates to `False`.

## Steps to Reproduce
1. Run `aiosyslogd` without the optional `gemini` dependency extra (`poetry install` without `-E gemini`).
2. Log in and navigate to `http://localhost:5141/profile`.
3. Open browser Developer Tools (F12) -> Console.
4. Observe the error: `Uncaught TypeError: Cannot read properties of null (reading 'addEventListener')` or `document.getElementById(...) is null`.

## Proposed Remediation
Wrap the Gemini-specific script block in `{% if gemini_available %}` or add element existence checks:

```javascript
document.addEventListener('DOMContentLoaded', function() {
    const saveBtn = document.getElementById('save-gemini-key');
    const clearBtn = document.getElementById('clear-gemini-key');
    const apiKeyInput = document.getElementById('gemini-api-key');

    if (!saveBtn || !apiKeyInput) {
        return;
    }
    // ... proceed with event listeners ...
});
```
