# Add Password Confirmation Field on User Management and Profile Forms

## Overview
Currently, `user_form.html` and `profile.html` have a single `<input type="password" name="password">` field without confirmation verification.

## Motivation & Impact
- **Security & UX**: If a user or admin mistypes a password when creating or updating an account, the user is immediately locked out without an easy recovery mechanism.
- **Error Reduction**: Confirmation matching ensures password intent before hashing and saving to `users.json`.

## Proposed Implementation
1. Add `<input type="password" class="form-control" id="confirm_password" name="confirm_password">` to `user_form.html` and `profile.html`.
2. Validate in `web.py` that `password == confirm_password` before calling `auth_manager.update_password` or `auth_manager.add_user`.
3. Add client-side validation to provide immediate feedback when fields mismatch.
