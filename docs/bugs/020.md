# Remove Inline Event Handlers for Strict Content Security Policy (CSP)

## Overview
Multiple templates contain inline HTML event handlers:
- `onchange="this.form.submit()"` on database dropdowns in `index.html` and `activity.html`.
- `onmouseover="..."` and `onmouseout="..."` on action buttons in `index.html`.
- `onclick="return confirm(...)"` on user deletion forms in `users.html`.

## Motivation & Impact
- **Security**: Modern security headers (Content Security Policy) block inline execution unless `'unsafe-inline'` is specified. Removing inline attributes allows enforcement of a strict CSP.
- **Separation of Concerns**: Keeps HTML semantic and logic isolated within dedicated JavaScript blocks/files.

## Proposed Implementation
1. Replace `onchange="this.form.submit()"` with:
   ```javascript
   const dbSelect = document.getElementById('db_file');
   if (dbSelect) dbSelect.addEventListener('change', () => dbSelect.form.submit());
   ```
2. Remove `onmouseover` and `onmouseout` handlers; rely entirely on CSS `:hover` states or standard Bootstrap button classes.
3. Attach event listeners with confirmation modals or dialogs in JavaScript for deletion actions.
