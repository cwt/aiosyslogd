# Add Dark Mode Color Scheme Support via Bootstrap 5.3+

## Overview
The application UI currently mixes dark navbar components (`navbar-dark bg-dark`) with fixed light container cards (`bg-white`). Bootstrap 5.3+ provides native CSS color mode support via `data-bs-theme`.

## Motivation & Impact
- **User Preference**: Syslog log analysis is frequently performed in dark environments or by users with dark system preferences.
- **Consistency**: Replaces fixed `bg-white` classes with theme-aware `bg-body` / `card` classes.

## Proposed Implementation
1. Add `data-bs-theme="auto"` to `<html lang="en">` in `base.html`.
2. Add a theme detection script to set theme based on `localStorage` or `prefers-color-scheme`.
3. Add a theme switcher icon dropdown to the navigation bar.
