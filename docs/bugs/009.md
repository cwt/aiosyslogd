# Regex Substring False Positives and Missing Word Boundaries in Dynamic Highlighter

## Bug Summary
The client-side Dynamic Highlighter on the Log Viewer page constructs a regular expression without word boundaries (`\b`):
```javascript
const allKeysRegexParts = originalCasingKeys.map(key => {
    const sanitizedKey = key.replace(/[^a-zA-Z0-9_-]/g, '');
    return `(${sanitizedKey}(?:\\s*=\\s*|\\s+)(?:'[^']+'|"[^"]+"|[\\S]+))`;
});
```
Furthermore, mapping the matched token to its color uses `.startsWith()` on the array:
```javascript
const matchedKey = originalCasingKeys.find(k => matchedValue.toLowerCase().startsWith(k.toLowerCase()));
```

## Severity & Impact
- **Severity**: Medium (Visual Corruption / Incorrect Highlighting)
- **Impact**:
  1. Highlighting a short key (e.g. `id`) incorrectly matches and highlights fields containing `id` as a substring (such as `srcid=10.0.0.1`, `msg_id=99`, or `valid=true`).
  2. If two highlighted keys share a common prefix (e.g. `app` and `application`), matches for `application=web` resolve to `app` because `"application=web".startsWith("app")` is true, styling it with the wrong highlight color.

## Affected Components
- File: [index.html](../../aiosyslogd/templates/index.html#L199-L217)
- Function: `applyAllHighlights()`

## Root Cause Analysis
1. Lack of `(?:\b|^)` prefix assertion before the key name.
2. Inadequate key resolution that fails to extract the exact key name before the delimiter (`=` or space).

## Steps to Reproduce
1. In the Log Viewer, enter `id` into the **Dynamic Highlighter** input and click **Highlight Key**.
2. Observe log rows containing `srcid=192.168.1.1` or `action=deny`.
3. The `id=192.168.1.1` substring inside `srcid=192.168.1.1` is highlighted, corrupting the log display.

## Proposed Remediation
1. Add word boundary assertions to the regex.
2. Extract the key part from the match and match exactly against the registered key list:

```javascript
const allKeysRegexParts = originalCasingKeys.map(key => {
    const sanitizedKey = key.replace(/[^a-zA-Z0-9_-]/g, '');
    return `(?:\\b${sanitizedKey}(?:\\s*=\\s*|\\s+)(?:'[^']+'|"[^"]+"|[\\S]+))`;
});
const combinedRegex = new RegExp(allKeysRegexParts.join('|'), 'gi');

// To find the exact key:
const keyMatch = matchedValue.match(/^([^=\s]+)/);
const extractedKey = keyMatch ? keyMatch[1].toLowerCase() : '';
const colorClass = keyColorMap[extractedKey] || highlightColors[0];
```
