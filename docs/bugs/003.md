# Arbitrary Database File Access in /api/activity

## Bug Summary
In `web.py`, both the `/` (index) and `/activity` web routes validate that the requested `db_file` parameter exists in the list returned by `get_available_databases(CFG)`. However, the `/api/activity` endpoint accepts any arbitrary string from `request.args.get("db_file")` and passes it directly to `run_activity_report(db_path=selected_db, ...)`.

## Severity & Impact
- **Severity**: High (Path Traversal / Unauthorized File Access)
- **Impact**: Authenticated users can provide arbitrary file paths (e.g. `/tmp/test.db` or relative paths outside the configured syslog storage) to execute SQLite queries against non-syslog databases or trigger database connection errors on system files.

## Affected Components
- File: [web.py](../../aiosyslogd/web.py#L454-L465)
- Function: `api_activity()`

```python
selected_db = request.args.get("db_file")
if not selected_db:
    return jsonify({"error": "Missing 'db_file' parameter."}), 400

report = await run_activity_report(
    db_path=selected_db,
    search_query=search_query,
    filters=filters,
    parser=get_activity_parser(
        CFG.get("activity", {}).get("parser", "fortios")
    ),
)
```

## Root Cause Analysis
The endpoint lacks the database existence validation present in the HTML routes:
```python
available_dbs = await get_available_databases(CFG)
if selected_db not in available_dbs:
    abort(404, "Database file not found.")
```

## Steps to Reproduce
1. Authenticate with the web server.
2. Send an API request specifying an arbitrary file path:
   ```bash
   curl -b "session=..." "http://localhost:5141/api/activity?q=test&db_file=/etc/passwd"
   ```
3. Observe that the backend attempts to connect to `file:/etc/passwd?mode=ro` as an SQLite database instead of returning an HTTP 400/404 error.

## Proposed Remediation
Validate `selected_db` against the list of authorized database files:

```python
available_dbs = await get_available_databases(CFG)
selected_db = request.args.get("db_file")
if not selected_db:
    return jsonify({"error": "Missing 'db_file' parameter."}), 400

if selected_db not in available_dbs:
    return jsonify({"error": "Database file not found or unauthorized."}), 404
```
