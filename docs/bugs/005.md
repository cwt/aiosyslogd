# Admin Self-Demotion and Self-Lockout in User Editing

## Bug Summary
While the `/users/delete/<username>` endpoint protects active administrators from deleting their own accounts (`if username == session.get("username"): flash("You cannot delete yourself.")`), the `/users/edit/<username>` endpoint does not perform any equivalent validation when updating admin status or enabled status.

## Severity & Impact
- **Severity**: Medium (Privilege Management / Accidental Lockout)
- **Impact**: An administrator editing their own account details can accidentally uncheck "Is Admin" or "Is Enabled", immediately revoking their own administrative access or disabling their login account.

## Affected Components
- File: [web.py](../../aiosyslogd/web.py#L341-L360)
- Function: `edit_user()`

```python
if request.method == "POST":
    form = await request.form
    new_password = form.get("password")
    is_admin = form.get("is_admin") == "on"
    is_enabled = form.get("is_enabled") == "on"

    if new_password:
        auth_manager.update_password(username, new_password)
        await flash("Password updated.", "success")

    auth_manager.set_user_admin_status(username, is_admin)
    auth_manager.set_user_enabled_status(username, is_enabled)
```

## Root Cause Analysis
The form handler processes the incoming `is_admin` and `is_enabled` boolean flags without verifying whether the target `username` matches the current logged-in session user (`session.get("username")`).

## Steps to Reproduce
1. Log in as user `admin`.
2. Navigate to `http://localhost:5141/users`.
3. Click **Edit** next to the `admin` account.
4. Uncheck **Is Admin** or **Is Enabled** and click **Save**.
5. Observe that the user's admin privilege is stripped or the account is disabled immediately.

## Proposed Remediation
Add a check in `edit_user()` to prevent self-demotion and self-disabling:

```python
current_username = session.get("username")
if username == current_username:
    if not is_admin:
        await flash("You cannot remove admin privileges from your own account.", "error")
        return redirect(url_for("list_users"))
    if not is_enabled:
        await flash("You cannot disable your own account.", "error")
        return redirect(url_for("list_users"))
```
