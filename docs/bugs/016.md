# Remove Dynamic JavaScript HTML Injection for Gemini Modals

## Overview
In `index.html`, lines 503–571 define a 70-line JavaScript template string (`geminiModalsHtml`) containing the markup for `#geminiAuthModal` and `#geminiModal`. On `DOMContentLoaded`, this string is inserted into `document.body` via `innerHTML`.

## Motivation & Impact
- **Developer Experience**: Embedding HTML in a JavaScript string defeats template linting, formatting (Prettier/Jinja formatters), and IDE syntax highlighting.
- **Maintainability**: Jinja2 directives, translations, and context variables cannot be cleanly rendered inside raw JavaScript strings.
- **Performance**: Eliminates unnecessary runtime DOM string parsing and element creation on every page load.

## Proposed Implementation
Move the modal HTML markup directly into `index.html` within the `{% if gemini_available %}` block before `{% endblock %}`:

```html
{% if gemini_available %}
<!-- Gemini Authentication Modal -->
<div class="modal fade" id="geminiAuthModal" tabindex="-1" aria-labelledby="geminiAuthModalLabel" aria-hidden="true">
    ...
</div>

<!-- Gemini Query Modal -->
<div class="modal fade" id="geminiModal" tabindex="-1" aria-labelledby="geminiModalLabel" aria-hidden="true">
    ...
</div>
{% endif %}
```

Remove `geminiModalsHtml` and the `DOMContentLoaded` insertion listener from the JavaScript script block.
